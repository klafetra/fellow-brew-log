# Fellow Brew Log

An interactive prototype for a brew tracking and AI recipe optimization feature for the Fellow Aiden coffee maker.

## Features

- **Bean library** — Track your coffee beans with origin, process, and roast details
- **Editable recipes** — Full Aiden profile control (bloom, pulses, temperatures) linked to each bean
- **Opus grind tracking** — Grind settings mapped to the Fellow Opus conical burr grinder (1-11 scale)
- **Flavor tags** — Quick-tap issue and positive flavor descriptors for each brew
- **AI recipe analysis** — Simulated AI-powered suggestions based on brew history
- **°F/°C toggle** — Temperature display preference
- **Fellow-style UI** — Dark theme matching the Fellow app design language

## Tech

- React 18 + Vite
- No external UI libraries — all custom components
- PWA-ready with manifest and mobile-optimized viewport

## Getting Started

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

## Background

Built as a product concept prototype to demonstrate a brew logging and AI recipe optimization feature for the Fellow Aiden precision coffee maker. Designed to complement the existing Fellow app's profile system with tracking, notes, and intelligent recipe suggestions.
